Job Specification

Role:

You will be on the server-side of logic, databases, and other components of a web application or software. You focus on what users don't see, ensuring the application runs smoothly and efficiently. This includes tasks like designing and managing databases, building APIs, and writing the code that connects the front-end to the server.
